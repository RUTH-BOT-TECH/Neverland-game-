# Asset credits and licensing

The project uses selected third-party assets in addition to Godot primitive meshes. Most listed models and textures are CC0 1.0 (public domain dedication): https://creativecommons.org/publicdomain/zero/1.0/ . The CMU motion-capture clips used by the adventurer have different terms, detailed below. Credits are retained for provenance.

- **Eldorian adventurer and Mira — generated using Ara 3D Gen, commit `b5bd34529bab90facfdf8f7baec43f155289bd45`:** `assets/models/eldoria_adventurer/Adventurer.glb` and `Mira.glb` are custom generated, skinned characters using the CC0 MakeHuman assets; Ara source code is MIT-licensed. Source: https://github.com/olatunde85/3d-gen . Its `SOURCE_LICENSE.txt` and `ARA_GENERATOR_LICENSE.txt` are included. The exported Walk, Run and Jump (where present) contain retargeted motion capture from the CMU Graphics Lab Motion Capture Database, using cgspeed's BVH conversion. CMU permits use in commercially sold products but prohibits direct resale of the data, even converted: https://mocap.cs.cmu.edu/ . Acknowledgement: **The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.** Do not resell the motion data separately.
  - Recipes: `assets/models/eldoria_adventurer/character_recipe.json` and `mira_recipe.json`. To regenerate, set up that exact Ara revision (Node 20+, `npm ci`, `npm run setup-assets`), copy `tools/generate_adventurer.ts` and `tools/generate_mira.ts` into its `scripts/` folder, and run each with `node --import tsx scripts/generate_adventurer.ts` and `node --import tsx scripts/generate_mira.ts` from the Ara root. These produce `Eldoria_Adventurer_unoptimized.glb` and `Eldoria_Mira_unoptimized.glb`. Run `python3 tools/optimize_glb_textures.py INPUT.glb OUTPUT.glb` from this project to limit embedded image dimensions to 1024 px (Pillow required). Godot imports the GLBs with embedded Basis Universal textures, avoiding extracted duplicate image files; Android compatibility and performance still need device tests. Ara's setup downloads hundreds of MB on the development machine; players do not download it at runtime. The current generated hero has approximately 25,340 triangles and 19 mesh surfaces; Mira has approximately 23,470 triangles and 13 surfaces. They need real Android profiling and further optimization, especially before multiple avatars are used.

- **Gobkit — KnightCaptain, PeasantMilitia, BloodironJuggernaut and TreeMed001:** `assets/models/gobkit/`. Source and license metadata: https://gobkit.com/api/free and https://gobkit.itch.io/gobkit-free-character-pack-vol-3 . `KnightCaptain.glb` and `PeasantMilitia.glb` are retained as earlier player and herald placeholders; `BloodironJuggernaut.glb` remains the active guardian placeholder; TreeMed001 is a stylized placeholder tree. For compatibility with Godot 4.6.3, the two character GLBs were repacked to give each sparse accessor independent buffer views; mesh, animation and image data remain unchanged.

The provided reference screenshot is used only for visual direction and is not included as a game asset. All other test geometry is generated in Godot from built-in primitives. No external asset downloads are required at runtime.

The Eldorian blue-and-gold banner design is original project artwork, generated offline by `tools/generate_royal_banner.py` (Pillow is needed only to regenerate it). Its five empty settings are decorative story symbolism, not collectible Orbs. The distant faceted ridge is generated procedurally by the project.
